# Sindhuja Muthusamy - Portfolio

My personal portfolio website. It's where I document my journey in tech: projects, hackathons, achievements, writing and what I'm learning along the way.

Live site: https://myportfolio-three-gamma-66.vercel.app/

## About this project

I wanted a portfolio that feels like a person made it, not a template. No heavy 3D graphics, no noisy animations. Just a warm, editorial design where the story comes first.

The guiding idea: story over effects, personality over templates, human first.

## What's inside

- **About and Journey** - a short intro and a "library" of chapters from school to my second year at REC
- **Coding record** - LeetCode and HackerRank progress
- **Projects** - built projects, hackathon work in progress, and concepts, with a filter to switch between them
- **Achievements** - academics, competitions, and recognition
- **Experience and leadership** - campus roles and community work
- **Writing** - articles from my blog, The Student Stack, with a quick preview reader
- **Skills** - grouped by domain, no percentage bars
- **Contact** - email, social links and a note form

## Built with

- HTML5
- Vanilla CSS (custom design system, warm paper and dark ink theme)
- JavaScript (no frameworks)
- Deployed on Vercel

There are zero dependencies, so there is nothing to install or build. The site is fully responsive and kept light and fast.

## Running it locally

1. Clone the repo

```bash
   git clone https://github.com/sindhujaamuthusamy72-byte/<repo-name>.git
   cd <repo-name>
```

2. Open `index.html` in your browser, or serve it with any static server:

```bash
   npx serve .
```

That's it.
